# 回测报告：这套打分到底有没有用

> 目的：验证「多周期共振评分」对未来涨跌有没有预测力，并据此校准权重。
> 复现方式：界面右栏「**回测校准**」按钮，或 `GET /api/backtest?symbol=BTC&tf=1h&horizon=24&bars=3000`

---

## 0. 先说结论

| 问题 | 答案 |
|---|---|
| 共振分能预测涨跌吗？ | **能，但很弱**（125 天样本 IC = +0.030，|IC|>0.05 才算有参考价值） |
| 多周期聚合比单周期强吗？ | **没有**（+0.030 vs −0.026，差异在噪声范围内） |
| 哪些分数段真的有用？ | **只有 +30~+50 这一段**（按方向期望 +0.63%） |
| 极端分数能用吗？ | **不能，要反着看**（>+50 做多平均亏 0.39%，胜率仅 36%） |
| 哪个周期信息量最大？ | **日线**（IC +0.163），周线最差且为负（−0.054） |

一句话：**它是个「多头择时器」，不是对称的多空信号系统。极端高分代表衰竭，不是加速。**

---

## 1. 方法（以及我踩到的坑）

### 1.1 严格无未来函数

回测必须保证「第 i 根 K 线时，只用第 i 根及之前的数据算分」。

第一版实现里有个隐蔽的 bug：`trend_structure()` 用的是**数组末尾** 120 根算摆动点。实时没问题（末尾就是当下），但在回测里对下标 `i` 求值时，它读到了 `i` 之后的数据 —— 这是典型的**未来函数**。

检测方法：用「截断到 i 的数据」和「全量数据在下标 i」分别算一次分，两者必须逐位相等。

```
修复前：i=150  切片算=+32.1637  全量算=+23.3918  不一致 <<< 有未来函数
修复后：i=150  切片算=+23.3918  全量算=+23.3918  一致
```

修复方式：在 `eval_at()` 里用 `bars[i-119 : i+1]` 现算结构，不再复用全量结果。
**任何回测如果没有做这个校验，结果都不可信。**

### 1.2 样本长度的陷阱（最重要的教训）

先用「15m 能覆盖的历史」做了第一次回测，窗口只有 15 天：

| 持有期 | IC（共振） | 看完直觉 |
|---|---|---|
| 4 根 | −0.044 | |
| 12 根 | −0.136 | |
| 24 根 | **−0.271** | 「信号是反的！」 |
| 72 根 | **−0.466** | 「越拿越亏，必须反着做！」 |

三个标的（BTC/ETH/SOL）全负，看起来像是铁证。

**但这是错的。** 那 15 天恰好是一段单边下跌行情，趋势跟随类指标在这段里系统性地买在反弹顶，必然产生负 IC。

把窗口拉到 **125 天**（分页加载 3000 根 1h，各周期按时间跨度换算取数），同一个模型：

| 持有期 | IC（共振） |
|---|---|
| 24 根 | **+0.030** |
| 72 根 | **+0.043** |

**从 −0.27 翻到 +0.03。** 15 天那一版不是发现了规律，是发现了那段行情。

> 由此得出的规矩：**样本少于 3 个月的技术指标回测，结论一律不能当真。**
> 单一行情会把 IC 推到 ±0.3 以上，那只是行情特征，不是信号强度。

## 2. 结果（BTC 1h，125 天，2916 样本）

### 2.1 整体预测力

| 指标 | 数值 | 解读 |
|---|---|---|
| IC（多周期共振） | **+0.030** | 极弱正相关 |
| IC（只看 1h） | −0.026 | 单周期基本无信息 |
| 强信号次数（\|分\|>50） | 239 次 | 约每 12 根出现一次 |

IC（Information Coefficient）= 评分与未来收益的相关系数。
经验参考：|IC| < 0.03 无信息，0.03~0.05 极弱，0.05~0.10 可用，>0.10 较强。

### 2.2 分桶明细（未来 24 根 ≈ 1 天）

| 分数区间 | 样本 | 均值收益 | 方向胜率 | **按方向期望** | 判定 |
|---|---|---|---|---|---|
| −∞ ~ −50 | 23 | +0.179% | 39.1% | **−0.179%** | 做空亏 |
| −50 ~ −30 | 250 | +0.281% | 47.2% | **−0.281%** | 做空亏 |
| −30 ~ −10 | 552 | −0.039% | 49.3% | +0.039% | 无效 |
| −10 ~ +10 | 647 | +0.064% | 53.8% | +0.121% | 略有效 |
| +10 ~ +30 | 679 | +0.056% | 53.8% | +0.056% | 无效 |
| **+30 ~ +50** | **549** | **+0.632%** | 51.4% | **+0.632%** | **最有效** |
| +50 ~ +∞ | 216 | −0.390% | 35.6% | **−0.390%** | **反向** |

**三个可直接用的发现：**

1. **只有 +30~+50 这一段有正期望**（+0.63%/天，样本 549 个，不算偶然）。
2. **负分区间全部无效** —— 做空的期望全是负的。这套打分识别不了下跌，只识别上涨中的延续。
3. **|分| > 50 是衰竭信号**。+50 以上做多，胜率只有 36%，平均亏 0.39%。分数冲到极端时，往往是短期动能耗尽，该减仓而不是加仓。

### 2.3 各周期单独预测力

| 周期 | IC | 权重（当前） | 评价 |
|---|---|---|---|
| 30m | −0.012 | 1.0 | 无信息 |
| 1h | −0.026 | 1.3 | 无信息 |
| 4h | −0.007 | 1.6 | 无信息 |
| **1d** | **+0.163** | 2.0 | **最强** |
| 1w | −0.054 | **2.2（最高）** | 最差，且为负 |

**这是最刺眼的一处：权重最高的周线，恰恰是唯一显著为负的周期。**
周线只有几十根样本、且滞后严重，把它设为最高权重等于让最迟钝的信号主导结论。

### 2.4 策略模拟

按分数方向每 24 根换仓，122 次交易：

| | 收益 |
|---|---|
| 按评分做 | **+18.69%** |
| 买入持有 | +14.94% |
| 胜率 | 50.8% |

仅小幅跑赢买入持有，且**不含手续费和滑点**。加千分之一手续费后优势基本消失。

> 这也说明：单靠这套打分做方向决策，不足以覆盖交易成本。它的价值在于「**辅助判断**」，不是「自动交易」。

## 3. 校准建议

基于以上结果，有三条：

### 3.1 权重（建议但未验证）

按 IC 比例粗调：

```python
TF_WEIGHT = {
    "15m": 0.5,   # 原 0.8
    "30m": 0.8,   # 原 1.0
    "1h":  1.0,   # 原 1.3
    "4h":  1.2,   # 原 1.6
    "1d":  2.5,   # 原 2.0  ← 提高，唯一有信息的周期
    "1w":  0.6,   # 原 2.2  ← 大幅降低
}
```

**但必须警告**：这是在同一段数据上「看着答案改参数」，属于**样本内优化**，会有过拟合。
正确做法是 walk-forward：用前 70% 定权重，后 30% 验证。这一步**尚未做**，所以上面的权重只是方向性建议，不是结论。

### 3.2 用法上的调整（比调权重更重要）

- **只在 +30~+50 区间考虑做多**，这是唯一有正期望的桶。
- **分数 > +50 时不要追**，那是衰竭区，应该观察减仓信号。
- **负分区间不要用来做空**，它没有空头预测力（负分桶做空期望全为负）。
- 想做空，需要另外一套逻辑（比如成交量分布上沿 + 结构破坏），当前模型没有。

### 3.3 诚实的定位

现在这套东西应该叫「**多头强弱打分**」，不是「多空信号」。界面上的「偏空/强空」标签在回测里没有支撑 —— 要么删掉，要么明确标注「无空头预测力」。

---

## 4. 局限（必须写清楚）

1. **只有一个标的、一个底周期**。BTC/1h/24根，没有跨标的、跨周期验证。
2. **样本内调参**。第 3.1 节的权重建议没有样本外验证。
3. **不含交易成本**。策略模拟的 +18.69% 是毛收益。
4. **125 天仍不算长**。技术上至少需要跨越一轮完整牛熊（2~3 年）才算稳。
5. **15m 被排除**。分页上限 6000 根，15m 只覆盖 62 天，与 3000 根 1h 的窗口不匹配，长时间回测时自动剔除。
6. **形态识别是规则式的**，不理解上下文，其信号权重 1.2+1.3 是否合理没有单独验证。

---

## 5. 下一步（按价值排序）

1. **Walk-forward 验证**：前 70% 定权重 → 后 30% 测 IC，看第 3.1 节的调整是真提升还是过拟合。
2. **加空头模型**：当前对下跌完全无预测力，这是最大的功能性缺口。
3. **接入实时记录**：把每天的实际评分与后续走势存下来，三个月后就有独立样本了。
4. **信号组合筛选**：现在是 18 个信号加权平均，可以试「少数几个信号同时满足」的组合，通常比加权平均更有效。
